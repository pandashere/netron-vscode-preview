原版 Netron 的强项

  • 它让你快速看清模型长什么样：有哪些节点、张量怎么流、每个算子的属性是什么。
  • 它很适合做第一次排查：模型能不能打开、结构是不是符合预期、某个节点在哪。
  • 它提供了成熟的图渲染和格式解析基础，本项目的增强能力都建立在这套体验之上。

本项目新增的工作台能力

  • 你不只是看模型，还可以从图里截出一段真正可运行的子图，并把它保存成稳定的 artifact。
  • 你可以直接跑这段子图、导出它、复制结构化文本，或者拿它和另一个格式的子图做结果比较。
  • 你可以把私有模型格式和自己的分析脚本接进来，让同一套界面服务于内部模型、内部 runtime 和内部 AI 工具。
Beyond Original Netron

原版 Netron 看模型；这个工作台让模型进入实验流程。

这里的重点不是把界面换个壳，而是把“看见问题”之后的动作接上：选一段图、确认边界、跑一下、导出来、和另一个结果对比，再把结构交给脚本或 AI 分析。

VS Code 里的模型工作台

模型不再需要离开工程目录单独打开。你可以在 VS Code 里从 Explorer 右键打开模型，和代码、配置、测试数据放在同一个工作上下文里。

  • 多个模型可以并排打开，方便对照不同版本、不同导出链路或不同格式。
  • 模型页面里直接集成 Model Tools，常用动作不需要跳到命令行。
  • 底部 Compare 和 AI 面板跟随当前模型状态，适合持续调试。

Host-managed ONNX

原版 Netron 更偏向前端查看。本项目把 ONNX 的重活放到 VS Code extension host：解析、裁剪、导出、推理都在宿主侧完成，webview 只负责展示。

  • 大模型和 external data 不需要整包塞进前端页面。
  • 裁剪后的子图可以导出成真正的 ONNX artifact，而不是一段截图或说明。
  • 推理走 ONNX Runtime，适合验证裁剪结果是否还能独立运行。

可确认的 Crop Artifact

用户在图上点 tensor 边来选择 start 和 end，确认后系统生成一个明确的 crop artifact。之后所有操作都围绕这个 artifact，而不是临时选择状态。

  • 保留 draft、confirmed、stale 状态，避免“我刚才选的是哪段图”这种不确定性。
  • provider 负责真正截出可推理子图，UI 负责把边界和状态讲清楚。
  • 同一个 artifact 可以继续用于导出、推理、比较和 AI 分析。

推理与输入导入

截完子图之后，可以马上跑一次，确认它不是“看起来被截出来了”，而是真的能独立接受输入、产出输出。

  • 没有测试输入时，可以用 zeros、ones、random 快速生成输入。
  • 需要复现真实问题时，可以导入 JSON 或 NPZ 输入数据。
  • 运行结果会展示 shape、dtype、统计信息和 sample，便于快速判断异常。

Compare Center

很多时候你关心的不是两张图是否长得一样，而是同一段语义在两个格式、两个 provider 或两个版本里跑出来是否一致。

  • 把两个 confirmed crop 放进 A/B slot，系统按输入输出契约尝试绑定。
  • 内部拓扑可以不同，只要 I/O dtype、rank、shape 兼容就能比较。
  • 输出 max abs、mean abs、RMSE、relative diff、cosine similarity 等指标。

脚本化 AI 分析

AI 面板不绑定某一个模型服务，也不是一个通用聊天框。它先让 exporter 把 crop 转成文本，再交给 analyzer 脚本决定怎么分析。

  • exporter 可以输出 edge list、JSON summary 或客户自定义文本格式。
  • analyzer 可以声明描述和最多 3 个用户输入框，用来把用户关注点和系统上下文拼成 prompt。
  • analyzer 可以调用私有模型、DeepSeek、内部 agent CLI，或任何一次性 message 模式工具。
  • 工具从全局目录热加载，UI 会展示是否可用以及不可用原因。
Workflow

围绕 confirmed crop 的一条主线。

所有高级功能都围绕同一个对象展开：用户确认过的 crop artifact。它让导出、推理、比较和 AI 分析拥有一致的目标和 provenance。

Open

在 VS Code 中打开 ONNX、Dev IR 或私有 provider 支持的模型。

Select

在 Netron 图上点击 tensor 边，选择 start 和 end 边界。

Confirm

生成 confirmed crop artifact，得到稳定的子图目标。

Run / Export

运行推理、导出模型 artifact、复制结构化文本。

Compare / Analyze

把子图放入 Compare Center，或交给 AI 面板分析。

Cross Format Compare

比较的是契约和结果，不是图长得像不像。

这让 ONNX、Dev IR、私有 IR 的子图可以在同一 Compare Center 中对齐。只要输入输出 dtype、rank、shape 兼容，就能运行比较。
